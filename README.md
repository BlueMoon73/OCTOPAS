# OCTOPAS
Oil spill Cleanup Through an Optimized Pragmatic Automated System



OCTOPAS is a novel automated system that will be able to clean up each oil spill pragmatically, based on the situation. It is a novel system intended to automate and improve oil spill cleanups. The main components of OCTOPAS are as follows: 


1.	Boat / Vehicle
2.	Software Application
3.	Drone 
4.	The Sorbent Deployment System 


### (1) The boat / vehicle, which is loaded with sorbents (OCTOPAS Boat) 
  - component that will be cleaning up the oil spill 
  - Automated  

###	(2) OCTOPAS App  
- Downloadable Desktop App  (in this repository) 
- Workflow: ![Image Processing Algorithm](https://user-images.githubusercontent.com/74512799/197408012-65e64a43-3c64-4eb7-9015-d4ce7217433e.jpg)

####	OCTOPAS Image Processing Module 
  -	A custom image processing algorithm, geared towards identifying the oil in a given image. 
  -	Input for the Algorithm will be the images captured by the drone
  -	Analyzes the image, and provides analytics of the image 


####	OCTOPAS ARM Controller Module  
  -	Controls the OCTOPAS ARM 
  - Analytics from the OCTOPAS ARM 


###	(3) OCTOPAS Drone
  - Used for taking images of the oil spill
  - These images will be processed in the OCTOPAS App  

###	(4) The Adaptive Release Mechanism (OCTOPAS ARM) 
  - The custom sorbent deployment system. 
  - Will deploy the appropriate sorbent, based on the processed image
  - Using custom made, 3D printed parts 

### OCTOPAS System  (OCTOPAS System ) 
  - Refers to all the components of OCTOPAS, working together.
